# Keny 1.0

Первый релиз Keny: Android-приложение, Linux-бинарники и сборка для OpenWrt ARM64 на базе sing-box-extended `v1.14.1-extended-2.7.2`.

- Транспорт Call: Телемост и VK, исправление совместимости VK creator/joiner.
- Согласованная ротация комнат Телемоста и восстановление соединений.
- Уведомление Android для ручного прохождения CAPTCHA VK.
- Встроенная проверка обновлений через GitHub Releases `Shtorm-glitch/Keny`.
- Android ID `keny.sfa`, версия `1.0.0`, versionCode `1`.
- Исправления ресурсов Compose, переводов и обработки недоступного системного Xposed-модуля.

## Файлы

- `keny.android-arm64-v8a.apk` — Android ARM64, Android 7.0 и новее.
- `keny.linux-amd64` — Linux x86-64.
- `keny.linux-arm64` — Linux ARM64.
- `keny.owrt-arm64` — самостоятельный ARM64-бинарник для OpenWrt, не пакет ipk/apk.
- `SFA-version-metadata.json` — метаданные встроенного обновлятора.
- `SHA256SUMS` — контрольные суммы файлов.

Профили и данные авторизации в публикацию не входят. Используйте собственные конфигурации. Android APK использует имеющийся сертификат Android Debug; сам APK — release без отладки. Ключ подписи не публикуется.

Проверено: 14 Android unit tests, полный lint без ошибок, сборки debug/release; APK ARM64 установлен на Android 16, запуск и перенос четырёх профилей проверены без запуска VPN. Целевые Go-тесты Call и сборки Linux проверены при подготовке ядра. Сборка и unit tests не доказывают работоспособность на любом операторе или во всех внешних сервисах. Для Xposed-функций модуль должен быть активирован для пакета `keny.sfa`; приложение открывается и при недоступном модуле.
