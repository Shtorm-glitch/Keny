# Keny 1.0.4

- Исправлено закрытие приложения при первом переключении из простого режима в Pro.
- Верхняя панель Pro сразу занимает своё место: карточка «Профили» больше не сдвигается после появления заголовка «Главная».
- В простом режиме над «Состоянием» добавлен таймер текущего соединения с общим отсчётом с Pro.
- Место под таймер выделено заранее: подключение не сдвигает остальные элементы экрана.

Android ARM64: keny.sfa, versionCode 5, релизная сборка с прежней подписью для обновления поверх установленной версии. Ядро сохранено из 1.0.3: 1.14.4-extended-2.7.3-keny.5. Linux/OpenWrt в этом UI-релизе не перевыпускаются.

Переключение после холодного запуска и положение карточки проверены на телефоне в debug-сборке. Сетевые настройки и профили не изменялись. Работа таймера на активном соединении в автоматическую проверку не входила.
